Interactive Regular Expression Engine

RegexForge is a custom compiler project developed for the CSE314 Compiler Design Lab. It provides end-to-end visibility into regular expression compilation—from tokenization and abstract syntax tree construction to Thompson NFA building, subset DFA conversion, and custom string matching.
